# Study V3.1 大资料库 · CloudBase 0 成本部署说明

## 目标
- 使用 CloudBase **FREE 免费体验环境**。
- 不升级个人版/标准版。
- 不开启按量付费/超限不停服。
- 免费额度用完时：宁可停服，不产生超额账单。
- 网站只使用“静态网站托管”，不启用 CloudBase 数据库、云函数、AI 等付费后端能力。
- 学习数据继续保存在你的浏览器本地；换设备前使用网站里的“导出全部学习数据”。

## 当前免费规则（以控制台最终显示为准）
- FREE：¥0/月。
- 每月 3,000 资源点。
- 免费环境暂不支持资源包和按量付费。
- 单次可续期 6 个月，不支持自动续费。
- 不手动升级，就不会自动转成付费套餐。

## 推荐部署方式：Git 仓库部署
大资料库需要执行 `npm run build` 联网抓取开放数据，所以不要直接只上传 preview-static。

在 CloudBase 控制台：
1. 新建/选择 **FREE 免费环境**。
2. 确认套餐显示 `¥0/月`。
3. 不点击“升级套餐”。
4. 不开启“按量付费 / 超限不停服”。免费环境通常本身也不允许开启。
5. 进入：静态网站托管 → 网站部署 → Git 仓库部署。
6. 连接放有本项目代码的 Git 仓库。
7. 构建配置填：
   - Node.js：22.x（20.x 也可以）
   - 安装命令：`npm install`
   - 构建命令：`npm run build`
   - 输出目录：`dist`
8. 开始部署。
9. 第一次构建会下载开放词库/语料，因此比普通静态网站慢。
10. 成功后点“访问应用”，会获得 `*.tcloudbaseapp.com` 默认网址。

## 大资料库构建内容
- 韩语：开放延世词汇 + 中韩真实例句。
- 英语：六级后 / 考研 / IELTS / TOEFL / GRE 进阶词 + 中英真实例句。
- 泰语：LEXiTRON 大词库 + 泰中真实例句。
- 完整来源与许可见 `SOURCES.md`。

## 如果在线大资料库构建失败
`preview-static/` 是可直接上传的离线预览版，功能完整但资料量较小。
先保证网站能用，再重新尝试 Git 构建大库。

## 0 成本安全检查
部署后到 CloudBase 的“套餐用量/计费”页面确认：
- 套餐：FREE / 免费体验版
- 费用：¥0/月
- 按量付费：未开启
- 超限不停服：未开启
- 自动续费：免费环境本身不支持

只要保持以上状态，超出免费额度时应进入“超限停服”，而不是继续产生按量费用。

## AI 费用说明
Study 默认使用 OpenRouter 的 `openrouter/free` 免费模型路由，未连接 AI 时不会产生任何 AI 调用。
不要手动改成付费模型，也不要在第三方 AI 账户里开启自动充值，就能保持 AI 侧 0 成本。

## 数据提醒
CloudBase 托管的是网站文件，不是你的学习记录。
你的单词、复习进度、笔记等仍主要存在浏览器本机，所以请定期使用“导出全部学习数据”备份。
