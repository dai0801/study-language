Study Language V3.1 · 大资料库版

定位：只给自己长期使用的韩语 / 英语 / 泰语学习网站。
无需账号，手机优先，电脑兼容；学习记录存在浏览器本地，可导入导出备份。

本版重点：
- 不再靠“每次加几百个词”更新内容。
- 部署时自动构建大资料库，构建完成后资料与网站同域加载。
- 韩语：以 Open Yonsei Korean Vocabulary 4,445 条开放词汇/表达为主，再加入真实中韩例句。
- 英语：你已通过六级，所以从 ECDICT 中筛选六级后、考研、IELTS、TOEFL、GRE 等进阶词；目标约 12,000 词，再加入真实中英例句。
- 泰语：以 LEXiTRON 2.0 为来源，目标整理约 22,000 条泰语词，再加入真实泰中例句。
- 三种语言的真实例句来自 Tatoeba，默认最多各整理约 2,500 对。
- 韩语尽量附罗马字；泰语用 RTGS / 音译辅助；英语显示音标。
- 大资料库按需加载，首页仍使用小核心库秒开，避免手机打开时卡顿。
- 资料很多时每次只渲染 40 条，支持搜索、按类型/主题筛选和“加入今日复习”。

重要：
1. dist/ 是离线预览版，包含小型核心库，可以直接预览页面。
2. 在 Vercel 等可联网构建的平台运行 `npm run build` 时，会自动抓取并生成完整大资料库到 dist/data/。
3. 如果开放数据源临时不可用，构建脚本会降级保留可用内容，不会让整个网站构建失败。
4. 完整数据来源与许可见 SOURCES.md。

暂时仍保留现有 AI、今日复习、聆听、笔记、快速记录、备份等功能。
